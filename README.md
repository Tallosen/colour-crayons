# Colour Crayons — Vacky Games

Головоломка: мелок закрашивает целую строку или столбец, новый цвет
ложится поверх старого. Нужно повторить рисунок-образец.

## Ссылки
- Игра: https://tallosen.github.io/colour-crayons/
- Privacy Policy: `privacy.html` в этом же репозитории

## Файлы
- `index.html` — игра целиком
- `privacy.html` — политика конфиденциальности
- `icon.png` — иконка 512×512
- `DESCRIPTION.md` — тексты и факты для подачи

## Запуск
Открыть `index.html`. Зависимостей нет — этот же файл идёт паблишеру.

## Как устроено
- **Генерация уровня** обратным ходом: сначала все строки, затем
  несколько столбцов — именно в таком порядке, иначе строка затирает
  след столбца и получается узор из одних полос.
- **Каждый уровень проверяется на решаемость** функцией `isSolvable`:
  узор разбирается обратно по мазкам с перебором, и пока он не
  разберётся полностью, вариант не выдаётся игроку.
- Результат проверяется: если почти все строки или столбцы вышли
  одноцветными, узор решается тривиально и выбрасывается. До 400
  попыток, плохой узор проскакивает примерно раз на 500 генераций.
- Число столбцов растёт с уровнем: `round(1 + lv/5)`.
- Поле 3×3 до 7 уровня, 4×4 до 16, дальше 5×5.
- Палитра растёт с трёх цветов до пяти.

## Что делает игру своей
- **ноты**: у каждого цвета своя, пентатоника — любой набор мазков
  звучит складно. Частоты в `COLORS[*].note`
- **короткий мелок** с 10 уровня: красит половину линии со своей стороны.
  Флаги `rowHalf` / `colHalf`, доля растёт до трети мелков

## Стиль
Тёплая бумага в точку, клетки как наклеенные бумажки с лёгким
поворотом и тенью, восковые мелки с бумажной обёрткой. Все контуры
рисуются слегка кривыми линиями через `wobbleRect` — форма привязана
к координатам, поэтому не дрожит между кадрами.

## Что уже есть
- прогресс и звёзды сохраняются (`localStorage`, при недоступности — в памяти)
- ряд кнопок под полем: домой, отмена хода, перезапуск, звук
- из игры можно вернуться в меню и сменить язык — требование Playgama
- недоигранный уровень запоминается: возврат в меню и обратно
  продолжает с того же места, сбрасывает только кнопка «заново»
- обучающая подсказка на первом уровне
- экран победы с готовым рисунком, звёздами и конфетти

## Требования Playgama по интерфейсу
Проверено по `game-requirements/user-experience-requirements`:
сохранение прогресса, кнопка звука, тишина при сворачивании вкладки,
доступ к выбору языка из любого места, глобус как универсальная иконка.

## Языки
Пятнадцать: en, es, pt, fr, de, it, pl, tr, id, hi, ja, ko, zh, ar, ru.

Английский показывается всем по умолчанию — витрина англоязычная,
а автоопределение по браузеру может ошибиться. Язык меняется кнопкой
на стартовом экране, выбор сохраняется.
Для арабского выставляется `dir="rtl"`.

Добавить язык — дописать блок в объект `STR`, больше нигде править
не нужно: список кнопок строится из его ключей.

## Playgama Bridge SDK — встроен
Подключается с CDN в `<head>`, рядом лежит `playgama-bridge-config.json`.

Что реализовано из обязательного:
- ожидание `bridge.initialize()` до старта игры
- язык из `platform.language` (выбор игрока имеет приоритет)
- прогресс через `storage.get/set`, без `localStorage`
- реакция на `AUDIO_STATE_CHANGED` и `PAUSE_STATE_CHANGED`
- `sendMessage('game_ready')` после загрузки
- `level_started` и `level_completed` на каждом уровне
- межстраничная реклама **раз в 15 пройденных уровней**,
  плюс ограничение SDK: не чаще 180 секунд, первые 90 секунд без рекламы

Без SDK (на своём сайте) игра работает через `localStorage` —
Bridge в таком окружении уходит в режим заглушки.

## Раскладки
Обе считаются, а не задаются числами: `layout()` для игрового экрана
и `winLayout()` для окна победы. Поэтому поле 5×5 не ломает вёрстку.

## Куда лезть за правкой
- сложность → `genLevel()`
- раскладка → `layout()`
- мелок → `crayon()`, клетка → `paperTile()`
- палитра → `COLORS`
