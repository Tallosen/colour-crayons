# Colour Crayons — Vacky Games

Головоломка: мелок закрашивает целую строку или столбец, новый цвет
ложится поверх старого. Нужно повторить рисунок-образец.

## Запуск
Открыть `index.html`. Зависимостей нет — этот же файл идёт паблишеру.

## Как устроено
- **Генерация уровня** обратным ходом: сначала случайные мазки, их
  результат становится образцом. Решение существует всегда, а число
  мазков сразу даёт `par` для звёзд.
- Поле 3×3 до 7 уровня, 4×4 до 16, дальше 5×5.
- Палитра растёт с трёх цветов до пяти.

## Стиль
Тёплая бумага в точку, клетки как наклеенные бумажки с лёгким
поворотом и тенью, восковые мелки с бумажной обёрткой. Все контуры
рисуются слегка кривыми линиями через `wobbleRect` — форма привязана
к координатам, поэтому не дрожит между кадрами.

## Что уже есть
- прогресс и звёзды сохраняются (`localStorage`, при недоступности — в памяти)
- отмена хода, перезапуск уровня, выключение звука
- обучающая подсказка на первом уровне
- экран победы с готовым рисунком, звёздами и конфетти

## Языки
Пятнадцать: en, es, pt, fr, de, it, pl, tr, id, hi, ja, ko, zh, ar, ru.

Английский показывается всем по умолчанию — витрина англоязычная,
а автоопределение по браузеру может ошибиться. Язык меняется кнопкой
на стартовом экране, выбор сохраняется.
Для арабского выставляется `dir="rtl"`.

Добавить язык — дописать блок в объект `STR`, больше нигде править
не нужно: список кнопок строится из его ключей.

## Перед публикацией в Playables
Заменить объект `store` на вызовы SDK платформы — там своё
хранилище, а `localStorage` внутри Playables недоступен.

## Раскладки
Обе считаются, а не задаются числами: `layout()` для игрового экрана
и `winLayout()` для окна победы. Поэтому поле 5×5 не ломает вёрстку.

## Куда лезть за правкой
- сложность → `genLevel()`
- раскладка → `layout()`
- мелок → `crayon()`, клетка → `paperTile()`
- палитра → `COLORS`
